*This ensures all future models share a strict set of rules so the main app can interact with them uniformly.*

> **Step 1: Create the Base Interface**
> Please write a Python module containing an abstract base class called `BaseModelingDashboard` that inherits from `PyQt6.QtWidgets.QWidget`.
